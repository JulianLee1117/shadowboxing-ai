## DINOv2 cost-only probe — 27 September

On the Apple M3 Max with 36 GiB RAM (38.65 GB), a fixed local float32 adapter loaded the [official non-register ViT-S/14 checkpoint](https://dl.fbaipublicfiles.com/dinov2/dinov2_vits14/dinov2_vits14_pretrain.pth) with `weights_only=True` and strict key/shape matching. No remote Python or hub entrypoint executed. Twelve already-inspected public Fort Jackson images supplied two same-frame pose-derived region crops each; neither Ramsay nor action labels were used. Every call computed normalized patch tokens `[2,256,384]` from two 224×224 RGB crops. Crop identity/localization was not validated; one weak-support region stayed in the fixed timing workload.

Each cell is **median / p95 milliseconds** for 36 calls. Three warmed trials used identical image order. CPU used one thread; MPS fallback was disabled and GPU work synchronized.
